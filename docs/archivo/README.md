# Archivo

Bitácoras de sesiones concretas y documentos de coordinación entre agentes que
**ya no describen el estado del proyecto**. Se conservan como registro: cuentan
cómo se llegó hasta aquí, y varias contienen el razonamiento detrás de
decisiones que siguen vigentes.

**No los uses para saber en qué estado está el proyecto.** Para eso:

| Quiero saber… | Lee |
|---|---|
| En qué estado está todo | [`../HANDOFF.md`](../HANDOFF.md) |
| Qué hallazgos hay abiertos | [`../AUDIT.md`](../AUDIT.md) |
| Qué falta y en qué orden | [`../ROADMAP.md`](../ROADMAP.md) |
| Cómo se trabaja aquí | [`../../AGENTS.md`](../../AGENTS.md) |
| Qué se decidió y por qué | [`../adr/`](../adr/) |

Sus enlaces internos apuntan a rutas de cuando se escribieron y algunos ya no
resuelven —los ADR se reorganizaron en `docs/adr/` el 08-08-2026—. Se dejan tal
cual: reescribir una bitácora la convierte en otra cosa.
